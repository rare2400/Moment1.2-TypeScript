# Moment 1.2 - Programmering i TypeScript

En webbapplikation som hanterar kursers 
* Kurskod,
* Kursnamn,
* Progression,
* Länk till kursplan.

Informationen om kursen skrivs in i ett formulär och skrivs sedan ut i en tabell med hjälp av TypeScript.
Kurserna som skrivits in läggs till i tabellen och sparas sedan i localStorage, för att ligga kvar även vid uppdatering av sidan. 
För att följa TypeScripts hårdtypning har typer för att definiera variabler, parametrar, returvärden samt interface använts i utvecklingen.
Npm-paketet vite har även använts för att automatisera utvecklingsprocessen och transpilera TypeScript-koden i till JavaScript,
vilket gör det möjligt för webbläsaren att tolka koden.

Uppgiften är publicerad på Netlify som stödjer en automatiserad publiceringsprocess och [här är länken till sidan](https://typescript1-rare2400.netlify.app/).
